My guesses · 我猜老师会改哪些变体考法

English

The real midterm keeps the same shape (a static CDN React app), so the instructor can only vary the data, the component interfaces and small JS requirements. I ranked the likely variations by how strongly the course material hints at them — and built all seven into this mock:

#Variation I guessedEvidence in the course material
1Rename the data variable and its inner array — here facts.items instead of riddles.riddlesExam p.3 “READ THIS CAREFULLY” makes a whole box out of the double name. A trap the examiner designed is the most likely thing to be renamed.
2Change the number of cards (9 → 12)Exam checklist: “The cards come from a map(), not nine hand-written tags”. A different count is the cheapest way to catch hard-coded cards.
3Show a count computed from the data in the headerExam “Want more practice?”: “a second line under the header that says how many riddles there are, worked out from the data”; Movie Night Step 12 uses props.initialMovies.length.
4Pass props as separate fields instead of one whole objectThe exam's Step 4 hint passes one object (<Fruit fruit={…} />), while Movie Night Step 11 passes separate props (title={ movie.title }). Both forms are taught; the examiner can switch.
5Conditional rendering with && (a STAR badge on some cards)Movie Night Steps 05 and 14 teach && badges inside Module 4. The mock says “no state”, but never excludes conditionals — the easiest Module 4 topic to add back.
6Date format and wording change — toLocaleDateString() + “Last updated:”Exam Step 6 hint offers both toDateString() and toLocaleDateString() and says “pick the one you like”, so format is not fixed.
7Filter the data before rendering (bonus)Exam “Want more practice?”: “show only the riddles whose answer starts with A”; Movie Night Step 15 already uses .filter(movie => movie.watched).
What I deliberately did NOT add: state, hooks, buttons, events or a random shuffle. The exam paper fixes the scope at Module 4 (see the Study Guide, Section 9), and randomness needs Math.random() + sort(), which the tutorial never teaches explicitly. It stays a pure, static render.
