Step 515 min

All nine with map() and key · 用 map() 和 key 显示九张

English

  • A for loop is a statement and cannot go inside JSX; map() is an expression that returns a new array (Movie Night, Step 12).
  • Each item needs a unique and stable key — the data already has id (exam Step 5 hint; Movie Night, Step 13). Put key on the element map() returns, not inside the child.
Check: nine cards numbered 1–9 in a 3×3 grid, no “unique key prop” warning.

中文

  • for 循环是语句,不能放进 JSX;map() 是表达式且返回新数组(Movie Night,第 12 步)。
  • 每一项都需要唯一且稳定的 key —— 数据里已有 id 字段(试卷第 5 步提示；Movie Night,第 13 步)。key 写在 map() 返回的元素上,不要写在子组件内部。
