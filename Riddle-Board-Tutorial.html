How to use this tutorial · 如何使用本教程

English

This tutorial walks you through the whole riddle-board-start assignment, step by step, showing the code to type at every step. It follows the exam paper's own plan (Section 5, seven steps) and uses only the ideas, terms and code style taught in Module 4 (Movie Night) and Code Lab Activities 1–4 — nothing outside the course.

  • Layout: English on the left, Chinese on the right. The code blocks below each step are shared by both languages — code needs no translation.

You need VS Code with the Live Server extension (by Ritwick Dey) — the same setup as Movie Night Step 00.

Not sure what each starter file is for? See the Study Guide (index.html), Section 3.

Open the project with Live Server · 用 Live Server 打开项目

English

Goal: open the starter the right way and set up your tools.

  1. Unzip riddle-board-start.zip (or use the folder you already have). Open the folder in VS Code.
  2. Right-click index.html → Open with Live Server. The page is empty now — that is normal; you have not written any React yet.

English

Render App with the header and footer · 渲染 App(页眉 + 空白看板 + 页脚)

English

Goal: in app.js, write a function component called App and render it into the root div. (These are exactly the two TODOs written in the starter file.)

  • A component is a function that returns React elements (Movie Night, Step 06). Its name must start with a capital letter: <App /> with a capital A is your component; a lowercase tag is read as an HTML tag.

  • Style note: the starter files define components as function declarations (function Header() {…}). Movie Night also shows the arrow-function form (const App = () => {…}, Step 06) — they behave the same. This tutorial keeps the starter's function style.
Check: save and refresh. You see the blue header and, at the bottom, “Generated today: current date”.

Show one riddle card with props · 用 props 显示一张卡片

English

Goal: make Riddle show the riddle it is given, instead of the placeholder text.

  • props are how data gets into a component. The parent writes them like HTML attributes where the component is used; the child receives them as one object, conventionally named props (Movie Night, Step 10).
  • Let the function take props: function Riddle(props). Then replace the three placeholder texts with { } expressions that read from the props. Anything between { and } is evaluated as JavaScript (Movie Night, Step 04): Riddle {props.riddle.id}, {props.riddle.question}, {props.riddle.answer}.
  • Test with one card: in App's board, write <Riddle riddle={riddles.riddles[0]} />. riddles.riddles[0] is the first riddle object ({id: 1, question: "…", answer: "…"}), so props.riddle.question is its question. Passing a whole object as one prop, then reading its fields in the child, is exactly what Movie Night does with the Movie component.
Check: one card shows “RIDDLE 1”, the keyboard question and “A keyboard.”.

Step 515 min

Show all nine with map() and key · 用 map() 和 key 显示全部九张

English

Goal: replace the single test card with a loop — one Riddle for every riddle in the array.

  • You cannot put a for loop inside JSX, because for is a statement, and JSX only accepts expressions. Arrays have a method that is an expression and returns a new array: map() (Movie Night, Step 12).
  • {riddles.riddles.map((riddle) => (<Riddle … />))} turns each of the nine riddle objects into one <Riddle /> element, and React renders them one after another.
  • Each item needs a key that is unique and stable — and the data already has one for you: the id field (exam paper, Step 5 hint; Movie Night, Step 13). Write key on the element that map() returns, not inside the child component. React keeps key for itself: props.key inside Riddle is undefined (Movie Night, Step 13 table).
Check: nine cards, numbered 1 to 9, in a three-by-three grid on a wide screen, and the Console has no “unique key prop” warning.

中文

目标：把单张测试卡换成一个循环 —— 数组里每条谜语对应一个 Riddle。

  • 不能把 for 循环放进 JSX,因为 for 是语句,而 JSX 只接受表达式。数组有一个方法本身就是表达式、又返回新数组：map()(Movie Night,第 12 步)。
  • {riddles.riddles.map((riddle) => (<Riddle … />))} 把九个谜语对象各变成一个 <Riddle /> 元素，React 再把它们依次渲染出来。
  • 每一项都需要一个唯一且稳定的 key —— 而数据里已经自带了:id 字段(试卷第 5 步提示；Movie Night,第 13 步)。key 要写在 map() 返回的那个元素上,不要写在子组件内部。React 自己保留 key:在 Riddle 里访问 props.key 是 undefined(Movie Night,第 13 步表格)。
检查：出现九张卡片，编号 1–9,宽屏下呈三行三列网格；Console 没有 “unique key prop” 警告。

Step 65 min

Today's date in the footer · 页脚显示今天的日期

English

Goal: replace “current date” in Footer.jsx with the real date.

  • new Date() gives you the date and time right now. Store it in a variable before the return — ordinary JavaScript can go there (Movie Night computes watchedCount the same way in Step 15) — then put it in the JSX with { }.
  • A Date object cannot go straight into JSX: turn it into text first (exam paper, Step 6 hint). Try these in the Console and pick one: new Date().toDateString() → “Wed Oct 28 2026”, or new Date().toLocaleDateString() → “10/28/2026”.
  • The date must be the real date, not typed in (requirement 5): tomorrow the page shows tomorrow's date by itself.
Check: the footer reads, for example, “Generated today: Wed Oct 28 2026”, and tomorrow it will show tomorrow's date.

中文

目标：把 Footer.jsx 里的 “current date” 换成真实日期。

  • new Date() 给出此刻的日期和时间。先把它存进一个变量，放在 return 之前 —— 那里可以写普通 JavaScript(Movie Night 第 15 步计算 watchedCount 就是这么做的)—— 然后用 { } 放进 JSX。
  • Date 对象不能直接放进 JSX:必须先转成文本(试卷第 6 步提示)。在 Console 里试试这两种，选一个:new Date().toDateString() → “Wed Oct 28 2026”,或 new Date().toLocaleDateString() → “10/28/2026”。
  • 日期必须是真实的日期，不许手写死(要求第 5 条)：明天打开页面，它要自己显示明天的日期。
检查：页脚显示类似 “Generated today: Wed Oct 28 2026”,明天会显示明天的日期。

// Footer.jsx: the bar fixed to the bottom of the page. Shows today's real date.
function Footer() {

  return (

  );
}
