English

Goal: open the starter the right way and set up your tools.

  1. Unzip riddle-board-start.zip (or use the folder you already have). Open the folder in VS Code.
  2. Right-click index.html → Open with Live Server. The page is empty now — that is normal; you have not written any React yet.

Render App with the header and footer · 渲染 App(页眉 + 空白看板 + 页脚)

English

Goal: in app.js, write a function component called App and render it into the root div. (These are exactly the two TODOs written in the starter file.)

  • A component is a function that returns React elements (Movie Night, Step 06). Its name must start with a capital letter: <App /> with a capital A is your component; a lowercase tag is read as an HTML tag.
  • App shows three parts: <Header />, an empty <div className="board"></div>, and <Footer />. A component must return one outer element, so wrap the three parts in a <div> (exam paper, Step 3 hint).

  • Style note: this tutorial follows the Professor's Proper code style — components you write are arrow functions (const App = () => {…}), expressions have spaces inside braces ({ props.question }), keys have spaces (key={ riddle.id }) and every data field is its own prop. The one exception is Header.jsx, given in the starter as function Header(): it is finished, so do not change it.
Check: save and refresh. You see the blue header and, at the bottom, “Generated today: current date”.

English

Step 515 min

Show all nine with map() and key · 用 map() 和 key 显示全部九张

English

Goal: replace the single test card with a loop — one Riddle for every riddle in the array.

  • You cannot put a for loop inside JSX, because for is a statement, and JSX only accepts expressions. Arrays have a method that is an expression and returns a new array: map() (Movie Night, Step 12).
  • { riddles.riddles.map(…) } turns each of the nine riddle objects into one <Riddle /> element, and React renders them one after another.
  • Each item needs a key that is unique and stable — and the data already has one for you: the id field (exam paper, Step 5 hint; Movie Night, Step 13). Write key on the element that map() returns, not inside the child component. React keeps key for itself: props.key inside Riddle is undefined (Movie Night, Step 13 table).
Check: nine cards, numbered 1 to 9, in a three-by-three grid on a wide screen, and the Console has no “unique key prop” warning.
Code Lab Activity 4 also practises filter() and conditional badges on top of map() + key. They are not required by this exam, so they are taught in the Extras section with the lab's own code rather than added to your app.

中文

目标：把单张测试卡换成一个循环 —— 数组里每条谜语对应一个 Riddle。

Activity 2 & 4 in full: &&, ? :, className, filter() · 活动 2/4 完整知识点

English

These four ideas are part of the official Code Lab activities, so they are included here for completeness. They come from index.html → The activities (Activities 2 and 4) and from activities.js / lang-zh.js.

  • { } expressions — curly braces put a JavaScript expression into JSX; { title } shows whatever the variable holds, so changing data changes the page.
  • && — condition && <element> renders the element only when the condition is true; when it is false React renders nothing.
  • ? : — condition ? A : B is an expression, so it can go inside { }; an if statement cannot.
  • className — class is a JavaScript reserved word, so JSX uses className; React warns in the console when it sees class.
  • filter() — keeps the items that pass a test; .length counts them. Conditional badges (STAFF PICK / WATCHED / NOT YET) only work when watched and staffPick are passed down as props.
Not exam requirements. The Riddle Board exam has no conditionals and no filtering — its marking scheme asks for four components, map(), a real date and clean code. Read this section to complete the four activities' knowledge, but do not add these lines to the files you submit. Practise them in the Code Lab instead.

以下四点是官方 Code Lab 活动的组成部分，因此在这里补全。内容来自 index.html → 四大活动(活动 2 与 4)以及 activities.js / lang-zh.js。

  • { } 表达式 —— 花括号把 JavaScript 表达式放进 JSX;{ title } 显示变量当前的值，数据一变页面就跟着变。
  • && —— condition && <element> 只在条件为 true 时渲染该元素；为 false 时 React 什么也不渲染。
  • ? : —— condition ? A : B 是表达式，可以放进 { };而 if 语句不行。
  • className —— class 是 JavaScript 保留字，所以 JSX 使用 className;React 看到 class 会在控制台给出警告。

English

Goal: replace “current date” in Footer.jsx with the real date.

  • new Date() gives you the date and time right now. Store it in a variable before the return — ordinary JavaScript can go there (Movie Night computes watchedCount the same way in Step 15) — then put it in the JSX with { }.
