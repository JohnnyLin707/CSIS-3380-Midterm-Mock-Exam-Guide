The exam at a glance · 考试概览

English

This mock midterm reproduces the programming part of the real midterm: a simple, static React app loaded from a CDN. You build one page that shows nine riddles, each on its own card, with a header at the top and today's date in a footer. There are no buttons, no state and no hooks.

The real midterm has two parts:

PartWhereMarks
Knowledge test (multiple choice, short answer)Blackboard5
Programming challenge (an app like this one)Submitted as a .zip in Blackboard25
  • Give yourself 90 minutes, work alone, then mark yourself with the checklist in Section 6.
  • Build the app in one folder, zip it and submit the zip. If the page does not open after unzipping, the mark is zero.
  • Submitting the empty starter files (or something unrelated) costs −3 marks.
The exam paper states: “everything you need was in Module 4 (Movie Night) and in Activities 1 to 4 of the React Code Lab.”

中文

这份模拟卷完全复刻真实期中考的编程部分：一个简单的、通过 CDN 加载的静态 React 应用。你要做一个页面，显示九条谜语，每条一张卡片，页面顶部有标题栏，底部显示今天的日期。没有按钮、没有 state、没有 hooks。

What to build & the 7-step plan · 构建目标与七步计划

English

Four components (Figure 2 of the exam):

ComponentFileShows
Appapp.jsEverything: <Header />, a <div className="board"> with one <Riddle /> per riddle, then <Footer />
Headercomponents/Header.jsxThe blue bar (done)
Riddlecomponents/Riddle.jsxOne card: number, question, answer
Footercomponents/Footer.jsx“Generated today:” + today's date

Each card reuses these finished classes (see mockup.html): .card, .card-number, .question, .answer.

Requirements: ① CDN React only (no Vite, no npm); ② four components; ③ read riddles from riddles.js via a <script> tag — never copy the data; ④ render the nine cards with map(), not nine hand-written tags; ⑤ real date in the footer; ⑥ no console errors (the Babel “in-browser transformer” warning is expected).

The 7 steps

  1. Open with Live Server (5 min). Right-click index.html → Open with Live Server; open DevTools and keep the Console open; also open mockup.html. Why: Babel loads your files over the network — file:// pages get blocked (blank page).
  2. Add the scripts to index.html (10 min). Order: React CDN → ReactDOM CDN → Babel CDN → riddles.js (plain script) → the three .jsx files (type="text/babel") → app.js (babel, last). Copy the three CDN lines from movie-night/index.html (Code Lab Activity 1). Check: no red errors; riddles.riddles.length → 9.
  3. Render App with header and footer (10 min). App returns <Header />, an empty <div className="board"></div> and <Footer /> wrapped in one outer <div>; then ReactDOM.createRoot(…).render(<App />). Source: README Steps 08 (step-08-compose/app.js), Code Lab Activity 2. Check: header + “Generated today: current date” visible.
  4. One card with props (15 min). Give Riddle a props parameter; replace the placeholder texts with { props.riddle.question } etc.; test with one card: <Riddle riddle={riddles.riddles[0]} />. Source: README Steps 10–11 (step-11-reusable/app.js), Code Lab Activity 3. Check: one real card shows.
  5. All nine with map() and key (15 min). Replace the test card with {riddles.riddles.map(r => <Riddle key={r.id} riddle={r} />)}. The data already has an id — use it. Source: README Steps 12–13 (step-13-keys/app.js), Code Lab Activity 4. Check: nine cards, 3×3 grid, no key warning.
  6. Today's date (5 min). In Footer.jsx: const today = new Date().toDateString(); before the return, then render {today}. A Date object cannot go into JSX directly — turn it into text. Check: real date shows, and shows tomorrow's date tomorrow.
  7. Clean up (5 min). Delete test code and console.logs; add one short comment above each component; save all files; final Console check.

中文

四个组件（试卷图 2）：

组件文件显示内容
Appapp.js一切：<Header />、一个 <div className="board">（每条谜语一个 <Riddle />）、然后 <Footer />
Headercomponents/Header.jsx蓝色标题栏（已完成）
Riddlecomponents/Riddle.jsx一张卡片：编号、问题、答案
Footercomponents/Footer.jsx“Generated today:” + 今天的日期

每张卡片复用这些已完成的类（见 mockup.html）：.card、.card-number、.question、.answer。

六条要求：① 只用 CDN 版 React（不用 Vite、不用 npm）；② 拆成四个组件；③ 通过 <script> 标签从 riddles.js 读取数据 —— 严禁把数据拷进自己的代码；④ 九张卡片用 map() 循环生成，不许手写九个标签；⑤ 页脚显示真实日期；⑥ 控制台无报错（Babel 的 “in-browser transformer” 黄色提示属正常）。

七个步骤

  1. 用 Live Server 打开（5 分钟）。右键 index.html → Open with Live Server；打开 DevTools 并全程保持 Console；同时打开 mockup.html 看目标效果。原因：Babel 要通过网络加载你的文件 —— file:// 打开会被浏览器拦截（白屏）。
  2. 给 index.html 加脚本（10 分钟）。顺序：React CDN → ReactDOM CDN → Babel CDN → riddles.js（普通 script）→ 三个 .jsx 组件文件（type="text/babel"）→ app.js（babel，放最后）。三行 CDN 直接照抄 movie-night/index.html（Code Lab Activity 1）。检查：无红色报错；riddles.riddles.length → 9。
  3. 渲染 App（10 分钟）。App 返回 <Header />、空的 <div className="board"></div> 和 <Footer />，三者包在唯一的外层 <div> 里；再用 ReactDOM.createRoot(…).render(<App />)。出处：README 第 08 步（step-08-compose/app.js）、Code Lab Activity 2。检查：标题栏 + “Generated today: current date” 出现。
  4. 用 props 显示一张卡片（15 分钟）。给 Riddle 加 props 参数；把占位文字换成 { props.riddle.question } 等；先用一张卡测试：<Riddle riddle={riddles.riddles[0]} />。出处：README 第 10–11 步（step-11-reusable/app.js）、Code Lab Activity 3。检查：出现一张真实数据的卡片。
  5. 用 map() 和 key 显示九张（15 分钟）。把测试卡换成 {riddles.riddles.map(r => <Riddle key={r.id} riddle={r} />)}。数据里自带 id 字段 —— 直接用它当 key。出处：README 第 12–13 步（step-13-keys/app.js）、Code Lab Activity 4。检查：九张卡片、宽屏 3×3 网格、无 key 警告。
  6. 今天的日期（5 分钟）。在 Footer.jsx 里，return 之前写 const today = new Date().toDateString();，然后在 JSX 里渲染 {today}。Date 对象不能直接放进 JSX —— 必须先转成文本。检查：显示真实日期，明天会显示明天的日期。
  7. 收尾清理（5 分钟）。删除测试代码和 console.log；每个组件上方加一句简短注释；保存全部文件；最后再检查一次 Console。

Common errors · 常见报错速查表

English

What you seeUsual causeFix
A blank page and no errorYou opened the file directly (file://…)Open it with Live Server (http://…)
React is not definedA Babel script runs before the React CDN scriptPut the three CDN scripts first
riddles is not definedriddles.js missing, misspelled, or loaded after app.jsLoad riddles.js before the Babel scripts; check the file name
Header is not defined (or Riddle, Footer)The component file is not loaded, or loads after app.jsAdd its <script type="text/babel"> before app.js
Unexpected token '<'A JSX file is loaded without type="text/babel"Add type="text/babel" to that script tag
Cannot read properties of undefined (reading 'map')You called riddles.map(…)The array is riddles.riddles
Each child in a list should have a unique "key" propKey missing, or on the wrong elementPut key={…} on the <Riddle /> that map() returns
Objects are not valid as a React childYou put a whole object (a riddle, or new Date()) inside { }Show one field (.question), or turn the date into text
The cards have no styleYou wrote class= instead of className=In JSX it is always className
Adjacent JSX elements must be wrappedA component returns two elements side by sideWrap them in one <div>
Only one card, or the same card nine timesYou passed riddles.riddles[0] inside map()Pass the item map() gives you
Read the error, then the file and line. The Console names the file and line — click it to jump there. Most errors here are a name typed differently in two places, or scripts in the wrong order.

English

Note · 笔记：Why only Module 4? · 为什么只用 Module 4 的知识？

English

A common question: why does riddle-board-start deliberately use only Module 4 knowledge and terms — is nothing from Modules 5 and 6 used? Three reasons, all from the exam paper and the course design itself:

① The exam paper draws the line itself

Page 1 of Mock-Midterm-Riddle-Board.pdf: “There are no buttons, no state and no hooks. It is a static React app: everything you need was in Module 4 (Movie Night) and in Activities 1 to 4 of the React Code Lab.” The scope is fixed by the examiner, not by us.

② It is a midterm — Modules 5–7 are assessed later

The mock reproduces the real midterm's programming part, which sits right after Module 4 is taught. The online Code Lab's own activity numbering shows where each topic belongs:

Code Lab activitiesModuleNeeded in this exam?
1–4 (add React, JSX, props, map() + key)Module 4Yes — exactly what this exam tests
5–6 (class components & state, lifting state up)Module 5No — after the midterm
7–9 (useState, useEffect, useContext)Module 6No — after the midterm
10 (React Router)Module 7No — after the midterm

Movie Night itself plants the same signpost in Step 07: “The − and + buttons do nothing yet. Making them change the score needs state, which is the next module.”

③ The app has no use for state or hooks

  • The data never changes: the nine riddles come from riddles.js and stay fixed while the page is open → nothing to store in useState.
  • No interaction: no buttons, no forms → no event handlers (Module 5/6 material).
  • The date is computed once at render: new Date().toDateString() before the return → no useEffect needed.

So all four components are pure function components: props in, JSX out.

Modules 5–6 are not useless — just not this exam. They belong to the final exam and the later projects. Their handouts are in this workspace: Module 5 - Stateful React Components/, Module 6 - React JS Hooks/, Module 7 - React Router, React Deployment/. This mock's job is to check the Module 4 fundamentals before the midterm.
