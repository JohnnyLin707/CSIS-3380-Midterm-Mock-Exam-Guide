Add React to the Movie Night Page · 为「电影之夜」页面加入 React

Module 4 · HTML · ~10 min

English

The Movie Night app.js is written, but index.html loads nothing, so the page is empty. A React page needs four things: an empty element for React to fill, the React library, a translator for JSX (Babel), and your code. Nothing is installed: the libraries come from unpkg, a free CDN, just as in class.

Steps

  1. Replace comment 1 with the root element: <div id="root"></div>. It starts empty; React draws the whole app inside it.
  2. Replace comment 2 with two script tags, in this order: React (builds components), then ReactDOM (draws them). ReactDOM needs React, so React must come first: <script crossorigin src="https://unpkg.com/react@18.3.1/umd/react.development.js"></script> and react-dom@18.3.1/umd/react-dom.development.js.
  3. Replace comment 3 with Babel (https://unpkg.com/@babel/standalone@7/babel.min.js): browsers cannot read JSX.
  4. Replace comment 4 with your app: <script type="text/babel" src="./app.js"></script>.
  5. Look at the preview: the Movie Night header and four movies appear. If empty, read the red message in the Console strip.

  4. Remember: JSX uses className, not class.

// EN: Professor's Proper code, Activity 2.
// 中文:Professor 标准代码,活动 2。
const movies = [
  { id: 1, title: "Spirited Away", year: 2001, genre: "Animation", rating: 5, watched: true, staffPick: true },
  { id: 2, title: "Inception", year: 2010, genre: "Sci-Fi", rating: 4, watched: true, staffPick: false },
  { id: 3, title: "The Grand Budapest Hotel", year: 2014, genre: "Comedy", rating: 4, watched: false, staffPick: true },
  { id: 4, title: "Coco", year: 2017, genre: "Animation", rating: 5, watched: false, staffPick: false }
];

const title = "Movie Night";
const showStats = true;
const watchedCount = movies.filter(movie => movie.watched).length;

const App = () => {
  return (
    <div className="watchlist">
      <header>
        {/* 1. the h1 from title */}
        <h1>{ title }</h1>

        {/* 2. the stats badge, only when showStats is true */}
        { showStats && <span className="stats">Movies: { movies.length }</span> }
      </header>

      <footer>
        {/* 3. All watched! or Watched 2 of 4 */}
        { watchedCount === movies.length
            ? "All watched!"
            : "Watched " + watchedCount + " of " + movies.length }
      </footer>
    </div>
  );
};

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<App />);
